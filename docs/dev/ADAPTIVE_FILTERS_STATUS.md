## 🔧 РЕАЛИЗОВАННЫЕ АЛГОРИТМЫ

### 1. **ЭКСПОНЕНЦИАЛЬНОЕ СГЛАЖИВАНИЕ** ✅
- **Формула:** S_t = α × X_t + (1-α) × S_{t-1}
- **Настройка:** Коэффициент α настраивается через веб-интерфейс
- **Дифференциация:** Разные коэффициенты для разных параметров
  - EC: α × 0.5 (очень агрессивное сглаживание)
  - NPK: α × 0.8 (умеренное сглаживание)
  - Остальные: α (обычное сглаживание)

### 2. **СТАТИСТИЧЕСКИЙ АНАЛИЗ** ✅
- **Окно статистики:** 10 последних измерений
- **Вычисление:** Среднее значение и стандартное отклонение
- **Минимальные требования:** 5 измерений для валидной статистики
- **Минимальное стандартное отклонение:** 0.1 для стабильности

### 3. **ОБНАРУЖЕНИЕ ВЫБРОСОВ** ✅
- **Алгоритм:** 3σ правило (настраиваемый порог)
- **Адаптивность:** Пороги автоматически подстраиваются под статистику
- **Обработка:** Выбросы заменяются на среднее значение
- **Специальная обработка EC:** Более строгие пороги (0.7×)

### 4. **ФИЛЬТР КАЛМАНА** ✅
- **Параметры:** Q (шум процесса), R (шум измерений)
- **Инициализация:** Автоматическая при первом измерении
- **Сброс:** При смене конфигурации
- **Эффективность:** Стабилизирует зашумленные данные

### 5. **СПЕЦИАЛИЗИРОВАННЫЙ ФИЛЬТР EC** ✅
- **Базовое значение:** Вычисляется из истории измерений
- **Паттерн выбросов:** Обнаружение повторяющихся скачков
- **Порог изменений:** 20% для аномальных скачков
- **Временное окно:** 10 последних измерений
