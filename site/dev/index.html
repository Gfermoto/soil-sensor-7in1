    🚀 Быстрый старт для разработчиков¶

    Требования¶

    • PlatformIO
    • Python 3.7+
    • ESP32 SDK
    • Реальное устройство ESP32 с датчиком JXCT

    Запуск тестов¶

    # Ультра-быстрое тестирование (5 секунд)
python scripts/ultra_quick_test.py

# Полное тестирование (2 минуты)
python scripts/run_simple_tests.py

# Детальное покрытие с моками
python test/test_mock_coverage.py

# ESP32 тесты
pio test -e esp32dev-test

# Native тесты (Windows)
pio test -e native-windows

    Production сборка¶

    # Production версия
pio run -e esp32dev-production

# Загрузка на устройство
pio run -e esp32dev-production -t upload

    🧪 Разделение тестов: критические и некритические¶

    • Критические тесты (test/test_critical_validation.py, test/test_format.py):
    • Должны всегда проходить.
    • Проверяются pre-commit hook и CI/CD pipeline.
    • Блокируют коммиты и мерджи при ошибках.
    • Некритические тесты (test/test_fake_sensor_values.py и др.):
    • Не блокируют коммиты.
    • Запускать вручную или в CI как allow-failures.

    Как запускать: 

    # Критические тесты
python test/test_critical_validation.py
python test/test_format.py

# Некритические тесты
python test/test_fake_sensor_values.py

    Pre-commit: - Скрипт scripts/pre-commit.py запускает только критические тесты. - Некритические тесты можно запускать вручную или в CI как allow-failures.
