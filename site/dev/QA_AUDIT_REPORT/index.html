    Источник: [Archie, 1942, AAPG Bulletin] ✅

    // Температурная поправка: pH_comp = pH_raw - 0.003×ΔT

    Источник: [Nernst, 1889, Physical Chemistry] ✅

    // Влажностная компенсация: NPK_comp = NPK_raw × (θ/θ₀)^0.5
