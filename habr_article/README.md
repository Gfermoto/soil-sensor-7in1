# Статья для Habr: IoT-датчик почвы 7-в-1

## Содержимое папки

- **article.md** — текст статьи в Markdown (можно вставить в редактор Habr)
- **images/** — скриншоты веб-интерфейса (сгенерированы скриптом `scripts/capture_habr_screenshots.py`)

## Важно: только реальные изображения

Используйте **только свои фото и скриншоты**. AI-иллюстрации и схемы из генераторов дают ошибки и неточности. В статье уже есть ASCII-схемы подключения из документации проекта — они проверены по коду.

## Что нужно от вас (фото и скриншоты)

### Обязательно

1. **Скриншоты веб-интерфейса** — уже есть в `images/` (01–04). Сгенерированы: `JXCT_DEVICE_IP=192.168.2.65 python scripts/capture_habr_screenshots.py`

2. **Фото собранного устройства** — ESP32 + датчик + провода. Желательно на фоне грунта или горшка.

### Желательно

3. **Фото датчика в почве** — зонд погружён в грунт (теплица, грядка, горшок).

4. **Скриншот Home Assistant** — карточки с данными датчика (если используется).

5. **Скриншот страницы калибровки** — web UI с настройками калибровки/компенсации.

### Опционально

6. **График** — экспорт из ThingSpeak или CSV за несколько дней (температура, влажность, EC).

7. **Схема на breadboard** — если собирали на макетной плате.

---

## Как публиковать на Habr

1. Зайти в [habr.com](https://habr.com) → Написать публикацию
2. Вставить текст из `article.md`
3. Загрузить свои фото/скриншоты в нужные места
4. Выбрать хабы: IoT, ESP32, Arduino, возможно «Точное земледелие» / «Умный дом»
5. Опубликовать
