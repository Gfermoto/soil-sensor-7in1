# Вклад в проект

Полное руководство: [docs/CONTRIBUTING.md](docs/CONTRIBUTING.md)

## Кратко

- **Issue:** описание проблемы, шаги воспроизведения, окружение
- **PR:** ветка от `main`, тесты проходят, код отформатирован
- **Тесты:** `pio test -e native`, `python scripts/run_e2e_tests.py`
- **Форматирование:** `python scripts/auto_format.py`
