# Отчёты тестирования

В этой папке сохраняются артефакты CI/CD:

- `*.json` — результаты тестов (генерируются автоматически)
- `*.html`, `*.xml` — отчёты покрытия (если включены)

Файлы `*.json`, `*.html`, `*.md`, `*.txt` игнорируются в `.gitignore`, кроме `README.md`, `MASTER_TEST_SUMMARY.md`, `technical-debt-assessment.md`.
